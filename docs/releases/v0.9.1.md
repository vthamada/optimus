# opTImus 0.9.1 — pré-release portátil

Primeiro pacote de avaliação para download. Aplicativo Windows com diagnóstico, inventário, IA local opcional e ferramentas consultivas. A interface organiza tarefas na tela inicial, navegação lateral, busca de consultas e requisitos próximos das ações. A versão também corrige a ordem das notificações de cancelamento.

## Usar

1. Baixe `opTImus-0.9.1-windows-x64.exe` na [release](https://github.com/vthamada/optimus/releases/tag/v0.9.1), ou extraia o ZIP opcional.
2. Abra o executável. O runtime .NET 10.0.14 acompanha o arquivo e extrai componentes em uma pasta temporária; não é necessário instalar SDK ou runtime.
3. Use **Visão geral → Iniciar diagnóstico**. A IA não é obrigatória para os dados básicos.
4. Configure ferramentas opcionais apenas quando precisar delas. O [guia da interface](../interface.md) detalha os fluxos.

O histórico padrão continua em `%LOCALAPPDATA%\opTImus`; não é incluído no pacote nem apagado ao trocar o executável. O pacote não cria atalhos, altera PATH ou instala componentes no Windows.

## Arquivos

- Executável portátil x64.
- ZIP com o mesmo executável, LEIA-ME, avisos de terceiros e SBOM CycloneDX.
- `SHA256SUMS.txt` para conferir os quatro arquivos de distribuição.
- Avisos de terceiros e SBOM disponíveis também como anexos separados.

Não há modelos GGUF, llama.cpp, restic, smartctl, CDB, Sysinternals, dumps, perfis pessoais ou dados de diagnóstico redistribuídos. A licença do código próprio não é definida pelos avisos das dependências.

## Validação e limites

- Aplicativo e suíte: [982 testes aprovados e limites da interface](../validation-ui-0.9.1.md).
- Execução portátil conferida sem DOTNET_ROOT/DOTNET_ROOT_X64, com primeiro uso, histórico SQLite e investigação real de registros/hardware em dados de verificação separados.
- ZIP conferido por CRC e identidade do executável; hashes SHA-256 acompanham os anexos. A publicação só é concluída após conferir os arquivos enviados.
- Ambiente nativo validado: Windows 11 x64. Não houve teste em uma VM limpa ou em toda combinação de versões do Windows.
- Protótipo sem assinatura Authenticode e sem instalador. Ausência de alertas não comprova saúde do computador.
- IA e ferramentas externas exigem configuração; relevância do modelo é experimental. CDB real e SMART físico têm validação pendente, conforme as notas anteriores.
- Não oferece limpeza, reparos, instalação de drivers, atualização de BIOS ou testes físicos de RAM. Nenhuma dessas ações foi executada na validação da release.

## Reproduzir o pacote portátil

Use o SDK isolado descrito no README, restaure as dependências travadas e execute na raiz:

```powershell
.\scripts\dev.ps1 -Task restore
& .\.tools\dotnet\dotnet.exe publish src/Optimus.Desktop/Optimus.Desktop.csproj `
  --configuration Release --runtime win-x64 --self-contained true --no-restore `
  --output artifacts/portable --disable-build-servers `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:IncludeAllContentForSelfExtract=true -p:DebugType=None -p:DebugSymbols=false
```

Não são habilitados trimming, AOT, instalação global ou download de motores/modelos. O executável de pasta gerado por `scripts/dev.ps1 -Task publish` continua disponível para desenvolvimento.
